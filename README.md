# 🛒 Miniloja

Uma aplicação web de e-commerce desenvolvida como projeto de estudos para aprender e praticar desenvolvimento full-stack.

## 📚 Sobre o Projeto

Este projeto foi criado com o objetivo de consolidar conhecimentos em desenvolvimento web, explorando diferentes tecnologias e conceitos como:

- Construção de interfaces interativas
- Processamento de dados no backend
- Integração entre frontend e backend
- Princípios de design e experiência do usuário

> ⚠️ Importante: este projeto ainda está em desenvolvimento e sendo utilizado principalmente para fins de estudo e aprendizado.

> Todos os dados utilizados aqui são completamente fictícios e foram criados apenas para demonstração e treinamento.

## 🛠️ Tecnologias Utilizadas

- **Frontend:** JavaScript
- **Backend:** PHP
- **Estrutura de páginas:** HTML

## 🎯 Objetivo

O objetivo deste projeto é servir como base para:

- Aprender e praticar desenvolvimento web
- Explorar arquitetura de um e-commerce simples
- Testar ideias de interface e fluxo de usuário
- Criar um portfólio de estudos

## 🧪 Dados Fictícios

Todos os dados presentes neste projeto, como produtos, clientes, pedidos e valores, são fictícios. Isso significa que:

- Nenhuma informação real é usada
- Os dados não representam transações reais
- O projeto pode ser usado para aprendizado e demonstração
- Qualquer pessoa pode estudar, adaptar ou evoluir o código

## 🚀 Como Rodar o Projeto

1. Clone o repositório:

```bash
git clone https://github.com/AlderlanCorrea/miniloja.git
cd miniloja
```

2. Configure o ambiente com um servidor web compatível com PHP.

3. Inicie o projeto e acesse no navegador.
