Sistema de Controle de Estoque
    1. Objetivo

Criar um sistema web simples de controle de estoque para uma loja virtual, utilizando tecnologias fundamentais do desenvolvimento web.

O projeto será desenvolvido para portfólio, com foco em demonstrar:

. Organização de código
. CRUD
. Banco de dados
. Comunicação entre frontend e backend
. Regras de negócio
. Controle de estoque
. Validação de dados
    2. Tecnologias
. Frontend
. HTML5
. CSS3
. JavaScript
. Backend
. PHP
. Banco de dados
. MySQL
. XAMPP

    6. Regras de negócio
Cadastro de produto
Nome obrigatório
Categoria obrigatória
Preço maior que zero
Estoque inicial igual ou maior que zero
Entrada
quantidade > 0

A quantidade será adicionada ao estoque atual.

Saída
quantidade > 0

E:

quantidade <= estoque atual

Caso contrário:

Estoque insuficiente.
